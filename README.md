# 🇸🇦 Saudi Irony Detection using NLP

This project investigates irony detection in Saudi dialect tweets using Natural Language Processing (NLP). Building on previous research, it reproduces baseline approaches and explores transformer-based Arabic language models to investigate effective strategies for detecting irony in Saudi dialect text.

---

##    About the Project

Detecting irony in Arabic social media is a challenging Natural Language Processing task because ironic expressions often rely on implicit meaning and contextual information rather than literal interpretation. Using the SaudiIrony (Sa'7r) dataset, this project investigates different approaches for detecting irony in Saudi dialect tweets and examines techniques that improve contextual representations for this task.

---

##    Objectives

- Detect irony in Saudi dialect tweets.
- Reproduce baseline approaches reported in previous studies.
- Explore transformer-based Arabic language models for irony detection.
- Investigate different preprocessing techniques for Arabic social media text.
- Enhance contextual representations using a modified AraBERT architecture.
- Evaluate different training strategies.

---

## 📂 Dataset

This project uses the **SaudiIrony (Sa'7r)** dataset, which contains Saudi dialect tweets annotated as:

- Ironic
- Non-Ironic

##    Methodology

The project workflow includes:

- Preparing and preprocessing the dataset.
- Reproducing baseline approaches from previous studies.
- Exploring transformer-based models, including MARBERT and a modified AraBERT architecture.
- Applying cross-validation and ensemble learning.
- Evaluating the proposed approaches using standard evaluation metrics.

---

##    Results

The experiments demonstrate the effectiveness of transformer-based approaches for Saudi dialect irony detection. The findings also highlight the inherent complexity of detecting irony in Saudi dialect text, emphasizing the importance of effective preprocessing, contextual representations, and well-designed training strategies.
